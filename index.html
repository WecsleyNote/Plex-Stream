Conexão com o Plex

Informe o endereço do seu servidor Plex e o token de autenticação. O token pode ser encontrado em qualquer mídia → XML → parâmetro X-Plex-Token.

📚
Selecionar Bibliotecas

Escolha quais bibliotecas aparecerão como catálogos no Stremio. Você pode selecionar uma ou mais. Se não selecionar nenhuma, o add-on funcionará só com streams via IMDB (sem catálogos).

🚀
Instalar no Stremio

Copie a URL abaixo e cole em Stremio → Add-ons → instalar via URL, ou clique em "Abrir no Stremio" para instalar automaticamente.
